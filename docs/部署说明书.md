# NoteForge 部署说明书

**版本：0.2.0 | 更新日期：2026年09月**

---

## 1. 系统要求

- **Rust**：1.70+（stable）
- **Node.js**：18+（推荐 20+）
- **系统库**（Linux）：`libxkbcommon fontconfig libgl webkit2gtk-4.1`
- **Tauri CLI**：`cargo install tauri-cli --version "^2"`

## 2. 从源码构建

```bash
# 安装前端依赖
cd frontend && npm install

# 构建并运行（开发模式）
cargo tauri dev

# 构建发布版本
npm run build && cargo build -p noteforge --release
```

## 3. Arch Linux / Manjaro 打包

```bash
cd pkg/manjaro
makepkg -si          # 需要 cmake、cargo-tauri（~/.cargo/bin）
# 依赖不齐时可跳过检查：
makepkg -d -f
```

已构建好的包可直接安装：

```bash
sudo pacman -U noteforge-0.1.0-3-x86_64.pkg.tar.zst
```

## 4. 运行

```bash
# 桌面应用
cargo tauri dev        # 开发模式
noteforge              # 安装后直接启动

# 生成测试库
cargo run -p nf-vaultgen -- generate --profile smoke --seed 42 --out ./vault

# CLI 浏览
cargo run -p nf-app -- info ./vault/vault
```

## 7. 同步配置与数据文件

vault 内 `.noteforge/` 目录存放同步运行时数据：

| 文件 | 说明 |
|---|---|
| `sync-config.json` | 同步目标配置（**不含**应用密码/同步密码，密码仅存内存） |
| `sync-state.json` | 上次同步快照（本地哈希 / 远端 etag），用于四象限增量 |
| `last-sync-report.json` | 最近一次同步报告明细 |
| `trash/` | 远端删除时本地文件的回收站 |
| `backup-首次同步前/` | 首次同步自动全量备份 |

远端（Nextcloud）`NoteForge/` 目录：镜像的目录树；加密模式下文件内容为 `NFC1` 魔数密文；`nf-sync-meta.json` 发布加密盐。
