# NoteForge 部署说明书

**版本：0.3.2 | 更新日期：2026年10月**

---

## 1. 系统要求

- **Rust**：1.70+（stable）
- **Node.js**：18+（推荐 20+）
- **系统库**（Linux）：`libxkbcommon fontconfig libgl webkit2gtk-4.1`
- **Tauri CLI**：`cargo install tauri-cli --version "^2"`

## 2. 从源码构建

```bash
# 安装前端依赖
cd frontend && npm install

# 构建并运行（开发模式）
cargo tauri dev

# 构建发布版本
npm run build && cargo build -p noteforge --release
```

## 3. Arch Linux / Manjaro 打包

```bash
cd pkg/manjaro
makepkg -si          # 需要 cmake、cargo-tauri（~/.cargo/bin）
# 依赖不齐时可跳过检查：
makepkg -d -f
```

已构建好的包可直接安装：

```bash
sudo pacman -U noteforge-0.3.2-1-x86_64.pkg.tar.zst
```

## 4. 运行

```bash
# 桌面应用
cargo tauri dev        # 开发模式
noteforge              # 安装后直接启动

# 生成测试库
cargo run -p nf-vaultgen -- generate --profile smoke --seed 42 --out ./vault

# CLI 浏览
cargo run -p nf-app -- info ./vault/vault
```

## 5. 快捷键

| 快捷键 | 功能 | 快捷键 | 功能 |
|--------|------|--------|------|
| Ctrl+O | 快速切换器 | Ctrl+B / Ctrl+I | 加粗 / 斜体 |
| Ctrl+P | 命令面板 | Ctrl+E | 行内代码 |
| Ctrl+S | 保存（另有 2s 自动保存） | Ctrl+K | 插入链接 |
| Ctrl+F / Ctrl+H | 查找 / 替换 | Ctrl+1..6 / Ctrl+0 | 标题级别 / 清除 |
| Ctrl+Shift+K | 代码块 | Ctrl+Shift+. / 8 | 引用 / 无序列表 |
| Ctrl+Shift+F | 焦点模式开关 | Ctrl+Shift+Y | 打字机模式开关 |

**编辑辅助模式**（对标 Typora 的 Focus / Typewriter，两模式均为纯视图行为，不改文档内容）：

| 模式 | 效果 | 开关 |
|------|------|------|
| 焦点模式 | 光标所在段落（连续非空行为一块）正常显示，其余段落淡出（`opacity: 0.3`） | 状态栏「焦点模式」按钮 / 命令面板 / Ctrl+Shift+F |
| 打字机模式 | 光标行始终垂直居中（编辑器 `padding-top/bottom: 45vh` + 滚动居中） | 状态栏「打字机模式」按钮 / 命令面板 / Ctrl+Shift+Y |

两模式开关状态分别持久化于 localStorage `nf-focus-mode` / `nf-typewriter-mode`（默认关闭），可同时开启、互不影响。

**表格编辑**（光标在表格内时生效；Advanced Tables 风格）：

| 快捷键 | 功能 |
|--------|------|
| Tab / Shift+Tab | 跳到下一格 / 上一格（自动选中格内容；末格 Tab 新增一行） |
| Enter | 移到下一行同列（末行 Enter 新建行） |
| Alt+↑ / Alt+↓ | 上方 / 下方插入一行 |
| Alt+Shift+↑ / ↓ | 删除当前行 |
| Alt+← / Alt+→ | 左侧 / 右侧插入一列 |
| Alt+Shift+← / → | 删除当前列 |
| Alt+Shift+F | 对齐整张表格（列宽取最宽单元格） |
| Alt+Shift+A / L / C / R | 切换当前列对齐（循环 / 直接指定左右中） |

输入停顿 350ms 后表格自动对齐，光标移出表格时也会补一次对齐；即输即显模式下光标行保留表格外观，悬浮工具条支持鼠标完成行/列增删与对齐切换。

## 6. 笔记链接与标签

- **#tag 自动补全**：编辑器中输入 `#` + 字符即弹出全库已有标签补全（子串匹配，含嵌套标签 `a/b`），选中后插入并带尾随空格；`[[链接#锚点]]`、`## 标题`、URL 锚点场景不会误触发
- **标签面板**：侧栏第三个页签「标签」，按引用次数排序展示全库标签（合并行内 `#tag` 与 frontmatter `tags:`），点击展开包含该标签的笔记并跳转；支持搜索过滤与手动重建索引；保存笔记后 3s 防抖自动重建
- **锚点跳转**：`[[笔记#标题]]`、`[[笔记#^block-id]]`、同笔记 `[[#标题]]` 点击后打开文件并滚动定位到对应行（编辑器居中显示）
- **快速切换器 / 命令面板排序**：文件名前缀 > 路径前缀 > 子串 > 跳字匹配；最近打开的文件 / 最近执行的命令加权（localStorage 各记 30 条）；空查询时快速切换器按最近使用排序

## 8. 同步配置与数据文件

vault 内 `.noteforge/` 目录存放同步运行时数据：

| 文件 | 说明 |
|---|---|
| `sync-config.json` | 同步目标配置（**不含**应用密码/同步密码，密码仅存内存） |
| `sync-state.json` | 上次同步快照（本地哈希 / 远端 etag），用于四象限增量 |
| `last-sync-report.json` | 最近一次同步报告明细 |
| `trash/` | 远端删除时本地文件的回收站 |
| `backup-首次同步前/` | 首次同步自动全量备份 |

远端（Nextcloud）`NoteForge/` 目录：镜像的目录树；加密模式下文件内容为 `NFC1` 魔数密文；`nf-sync-meta.json` 发布加密盐。

## 9. 测试

```bash
cargo test --workspace        # 全部测试目标
cd frontend && npm run build  # tsc -b 类型检查 + vite 构建
cd frontend && npm run test   # vitest：118 个用例

# 插件管理命令（含目录扫描/启停/卸载/市场搜索）
cargo test -p noteforge plugin_cmd
# 真实网络的市场安装验证（默认跳过以保持离线可测）
NOTEFORGE_NET_TESTS=1 cargo test -p noteforge plugin_cmd::tests::install_plugin_from_market

# Obsidian 插件兼容性测试（41 插件分层样本）
cd frontend
npx vite build --config vite.harness.config.ts   # 打 harness 包
node scripts/compat/select-sample.mjs 40          # 生成分层样本
node scripts/compat/run.mjs                        # 跑全量并产出报告
node scripts/compat/run.mjs --report-only          # 只重生成报告
node scripts/compat/analyze-imports.mjs             # 静态扫描缺失的 API
```

兼容性报告输出到 `wk/AIReports/noteforge-obsidian-plugin-compat-<日期>.md`，
兼容层的能力与已知限制见 `frontend/src/plugins/README.md`。
