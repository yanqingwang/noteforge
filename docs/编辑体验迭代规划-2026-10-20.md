## 二、迭代路线（四个阶段，按「友好度收益 ÷ 风险」排序）

### 阶段 A：真·所见即所得（最高优先级）

**A1｜行内标记展开粒度：整行 → 仅光标触及的片段**（核心改造）
- **现状**：`lineFocused()` 仅比较行号，光标在该行 → 该行所有 `**`/`*`/`` ` `` 全部回显源码。
- **目标（Typora 行为）**：标记默认始终隐藏；仅当光标/选区与该节点的**标记区间或内容区间重叠**时，才展开这一个节点的标记。
- **做法**：把 `lineFocused(from,to)` 替换为 `rangeTouched(from,to,view)`——遍历 `state.selection.ranges`，判断是否存在 `range.to > from && range.from < to` 的交集。
- **注意**：`Decoration.replace` 隐藏的区间在光标进入后必须能被编辑，展开时机与 `viewportChanged`/`selectionSet` 的 ViewPlugin 重算要正确联动；**禁止在 update 阶段 dispatch**（既有教训）。
- **验收**：单测覆盖「光标在粗体之外 → 标记隐藏；光标落在 `**` 内 → 仅该处展开；多光标各自独立展开」；桌面截屏对比光标移入/移出。

**A2｜`#tag` live 渲染为标签胶囊**
- 先核实是否已渲染；未渲染则用 `Decoration.mark` + `lp-tag` 样式（点击可跳标签面板过滤）。

**A3｜链接体验**
- `[文本](url)` 渲染为「文本 + 外链图标」，`Ctrl/Cmd+Click` 打开外部浏览器；
- 粘贴裸 URL（`http(s)://` 或 `www.`）自动包成 `[域名](url)`。

**A4｜图片体验增强**
- 支持 `![[img|300]]` 宽度语法；图片加载失败显示占位与路径提示（避免空白块）。

### 阶段 B：沉浸写作（低风险、感知强）

**B1｜Focus 模式**：当前段落（或当前块）正常显示，其余段落降低不透明度；用 `Decoration.line` 实现（**块级装饰不能由 ViewPlugin 直接提供**，沿用现有 line 装饰模式规避 RangeError）。

**B2｜Typewriter 模式**：光标行始终垂直居中；用 `EditorView.scrollIntoView(pos, {y:"center"})` + 上下留白 padding 实现。

**B3｜禅模式**：一键隐藏侧栏、右侧栏、状态栏，进入纯写作。

- **验收**：三种模式各配开关（状态栏/命令面板），持久化到 localStorage；模式互斥关系明确。

### 阶段 C：智能输入与效率

**C1｜智能粘贴**：URL 自动成链接；富文本/HTML 粘贴转 markdown（Typora 能力）。
**C2｜选区浮动格式条**：选中文本后浮现 B/I/删除线/行内代码/链接 快捷按钮（鼠标用户友好度）。
**C3｜自动配对增强**：中文全角括号/引号配对、Markdown 强调标记智能配对。
**C4｜表格补完**：列宽拖拽、TSV/表格互相转换、导出。

### 阶段 D：公式与导出

**D1｜KaTeX 数学公式**：`$...$` 行内、`$$...$$` 块级，用 `Decoration.widget` 插入渲染结果。
**D2｜导出**：PDF / 独立 HTML / 长图（Typora 强项，也便于分发）。

## 三、单轮执行模板（沿用既有工作流）

1. 改前先写/改单测（纯函数优先，UI 交互用组件级测试）；
2. `cd frontend && npx vitest run` + `npm run build`（tsc -b && vite build）；
3. `cargo build -p noteforge`，启动二进制截屏验证（Wayland 无键鼠注入，交互靠单测）；
4. 追加 `docs/verification-log.md`；用户可见行为变更同步 `docs/部署说明书.md`；
5. 中文详细 commit，push origin main。

## 四、风险与约束（勿重犯）

- CM6 update 阶段禁止 `dispatch`（需 microtask/rAF 延后）；
- 整段替换不要用 `mapPos` 保留光标（会被吸到替换区末尾）；
- 块级 `Decoration` 不能由 `ViewPlugin` 提供，只能 `Decoration.line` 间接实现（浮层 UI 直接挂 `view.dom`）；
- 大 vault（2930 笔记）下任何全库扫描命令走 `async + spawn_blocking`。

## 五、建议起步顺序

| 顺序 | 项目 | 理由 |
|---|---|---|
| 1 | **A1 展开粒度** | 与 Typora 的体感差距最大，是「友好度」的定义性能力 |
| 2 | **B1 + B2 沉浸模式** | 风险最低、感知最强，可快速交付正反馈 |
| 3 | **A3 链接 + C1 智能粘贴** | 日常输入高频，收益直接 |
| 4 | **D1 公式 / D2 导出** | 补齐差异化，依赖前端新包，放后面 |
