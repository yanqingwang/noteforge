# NoteForge 产品说明书

**版本：0.2.0 | 更新日期：2026年09月**

---

## 1. 产品概述

NoteForge 是一款纯 Rust 实现的本地优先（local-first）Markdown 知识管理桌面应用，对标 Obsidian。

### 设计哲学

1. **数据主权**：文件是唯一真实数据源
2. **性能**：启动快、大 Vault 不卡顿、编辑器低资源占用
3. **友好**：Typora/MarkText 风格的即时渲染编辑
4. **隐私**：可选的端到端加密同步，服务器只存密文

## 3. 功能列表

### 3.1 编辑器（CodeMirror 6）

- **四种编辑模式**：源码 / 分栏 / 即输即显 / 预览，切换不丢撤销栈
- **Live Preview 即时渲染**（「即输即显」）：
  - 非光标行隐藏语法标记：`**加粗**`、`*斜体*`、`~~删除线~~`、行内代码只显示渲染效果
  - 标题按级放大字号并隐藏 `#`；引用显示左侧竖条并隐藏 `>`
  - 代码块语法高亮（highlight.js，30+ 常用语言内置、其余按需加载）
  - 光标所在行自动回显源码，编辑所见即所得且不干扰输入
- **Wikilink 双链**：`[[链接|别名]]` 渲染为可点击胶囊，点击跳转；`[[` 触发自动补全（上下键选择、Esc 关闭）
- **图片嵌入**：`![[图片.png]]` 直接内联预览
- **任务列表**：`- [ ]` 渲染为可点击复选框，点击直接勾选回写文档
- **格式快捷键**（16 组）：

| 快捷键 | 功能 | 快捷键 | 功能 |
|---|---|---|---|
| Ctrl+B | 加粗 | Ctrl+1..6 | 一到六级标题 |
| Ctrl+I | 斜体 | Ctrl+0 | 清除行前缀 |
| Ctrl+E | 行内代码 | Ctrl+Shift+. | 引用 |
| Ctrl+Shift+X | 删除线 | Ctrl+Shift+8 | 无序列表 |
| Ctrl+K | 插入链接 | Ctrl+Shift+K | 代码块 |

- **列表续行**：回车自动续行 `- `/`1. `/`> `/`- [ ] `（有序列表自动递增），空项回车取消列表
- **自动配对**：`(`、`[`、`{`、`` ` ``、`"` 输入自动补全另一半，选区跨越时成对包裹
- **自动保存**：停止输入 2 秒自动落盘（原子写：临时文件 + rename）；Ctrl+S 随时手动保存
- **粘贴/拖拽图片**：自动保存到 `attachments/年-月/时间戳.扩展名` 并插入 `![[…]]`
- **文内查找替换**：Ctrl+F / Ctrl+H（CodeMirror search 面板）

### 3.2 笔记管理

- 打开 Vault（目录选择对话框）、文件树、新建/删除笔记、全文搜索、反链、知识图谱
- 快速切换器 Ctrl+O、命令面板 Ctrl+P
- Vault 统计、菜单栏、Vault 配置（排除目录、附件目录等）

### 3.3 Nextcloud 同步（加密镜像）

vault 目录与 Nextcloud 指定远程目录 **1:1 镜像**，保留目录结构与 `.md` 原文；默认开启**内容加密**——文件以 AES-256-GCM 加密后上传，服务器只存密文。

**配置**（设置 → ☁ Nextcloud 同步）：

| 项 | 说明 |
|---|---|
| 服务器地址 | 如 `https://pan.example.com`（或直接填完整 DAV URL） |
| 用户名 / 应用密码 | 应用密码在 Nextcloud「设置 → 安全 → 设备与活动」生成；**密码仅保存在本机内存，不落盘** |
| 远程目录 | 默认 `NoteForge` |
| 加密同步 | 默认开启；关闭则明文镜像。同步密码不落盘，其他设备需输入同一密码 |
| 同步方向 | 双向（默认）/ 仅上传 / 仅下载 |
| 忽略规则 | 默认忽略 `.noteforge/` `.obsidian/` `.git/` `*.tmp` 等，可追加 glob |

**同步机制**：

- **四象限增量**：本地快照（mtime+size+懒 SHA-256）对比远端 etag，只传输变更文件
- **首次同步**：三选一引导——双向增量（推荐，两侧同名但内容不同会保留冲突副本）/ 以本地为准 / 以服务器为准；开始前自动备份到 `.noteforge/backup-首次同步前/`
- **冲突处理**：双方都改 → 本地版本保留为 `原名 (冲突 日期-时间).md`，远端版本作为正身下载
- **删除保护**：本地删除 → 服务器文件进 Nextcloud 回收站；远端删除 → 本地文件移入 `.noteforge/trash/`
- **多设备**：各设备输入同一同步密码即可（加密盐发布在远端 `nf-sync-meta.json`，密码永不传输）
- 同步报告：每次同步生成明细（上传/下载/冲突/删除/失败逐项），设置内可查看上次报告

## 4. 技术栈

| 领域 | 选型 |
|------|------|
| GUI 框架 | **Tauri 2** |

| 同步 | WebDAV（Nextcloud remote.php/dav）+ AES-256-GCM |
| 插件运行时 | wasmtime |
